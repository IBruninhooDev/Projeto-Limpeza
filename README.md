📝 Descrição do Projeto

Este projeto é um website estático desenvolvido para a Limpeza de Casa, uma empresa que oferece serviços profissionais de limpeza residencial e comercial. O site foi projetado para ser intuitivo e informativo, destacando a gama de serviços oferecidos e facilitando o contato com os clientes.

✨ Funcionalidades e Serviços

O website apresenta as seguintes funcionalidades e serviços:

• Página Inicial (index.html): Apresenta a empresa, seus valores e um resumo do processo de trabalho.

• Página de Serviços (services.html): Detalha todos os serviços de limpeza oferecidos, incluindo:

• Limpeza de Casa (regular e profunda)

• Limpeza Pós-Obra

• Limpeza de Mudança (entrada e saída)

• Limpeza de Roupas

• Limpeza de Escritório
---
• Página de Contato (contact.html): Fornece informações e formulários para que os clientes possam entrar em contato.

• Navegação Intuitiva: Menu de navegação claro e responsivo para fácil acesso às diferentes seções do site.

• Design Responsivo: O site é adaptado para visualização em diversos dispositivos (desktops, tablets e smartphones).

🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias web padrão:

• HTML5: Para a estrutura e conteúdo das páginas.

• CSS3: Para estilização, incluindo root.css, style.css, contact.css e services.css para um design limpo e moderno.

• JavaScript: Para interatividade básica, como o menu de navegação responsivo e a atualização dinâmica do ano no rodapé.

• SVG Icons: Utilização de ícones escaláveis para uma melhor experiência visual.

# 🚀 Como Rodar o Projeto

Para visualizar o projeto localmente, siga os passos abaixo:

1. **Clone o repositório:**

```bash
git clone https://github.com/IBrunooDev/Projeto-Limpeza-main.git
```

2. **Navegue até o diretório do projeto:**

```bash
cd Projeto-Limpeza-main
```

3.Abra o arquivo index.html:
Simplesmente abra o arquivo index.html em seu navegador web preferido. Não é necessário um servidor web para este projeto estático.
